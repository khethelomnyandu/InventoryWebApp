# InventoryWebApp

A **full-stack Inventory Management Web Application** built for internship/portfolio purposes.  

- **Backend:** C# ASP.NET Core Web API with SQLite  
- **Frontend:** HTML, CSS, JavaScript  
- **Features:**  
  - Add, edit, delete, and view products (full CRUD)  
  - Persistent storage with SQLite  
  - Polished, responsive, modern UI  
  - Table display with hover effects and color-coded action buttons  


## Usage

1. Clone the repository:
